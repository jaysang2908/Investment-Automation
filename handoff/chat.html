Part 2 — Google Trends & Sector Keywords
Justin

and not necessarily just specifically for the ticker symbol. A lot of the narrative could be sector specific… How do we ensure we capture this?

Claude

Good catch. We solve this with a sector-level keyword layer in Google Trends. Each narrative theme maps to 1–2 sector search terms that run alongside the ticker in the same pytrends query — so they're all on the same 0–100 relative scale and directly comparable.

For example, "AI / Machine Learning" → ["AI stocks", "artificial intelligence investing"]. If you're looking at MU, you'd also track "HBM memory, DRAM cycle" as custom terms.

Key insight: if "HBM memory" is trending but "MU" isn't yet — that's an early entry signal, not a red flag. The sector wave hasn't been priced into the name. Scoring logic: hot sector + quiet ticker = MOD (opportunity), not LOW. Hot sector + hot ticker = 2 bullish votes.

Justin

sorry what the hell do those numbers mean? like 100/100 and 38-46 are they units of something

Claude

Google Trends doesn't give you actual search volume. It gives a relative 0–100 index:

  • 100 = the peak day in the queried window (not "100% of all searches" — just the busiest day for that term in that period)
  • 50 = half as much interest as that peak day
  • 0 = basically no searches

The ratio we compute (e.g. 2.0x) is: average of last 7 days ÷ average of the prior period. So 2.0x = last 7 days getting double the search interest vs the baseline. That's the surge signal we're after.

Critically — because all terms run in the same query, they share the same 0–100 scale and are directly comparable to each other.

ah cool that makes sense, thanks, yes please add custom search terms functionality. How prescriptive is this btw? like is it the EXACT words i put in the search term or will it also show data/analyse relevant stuff similar to that search query

Claude

Phrase-match, not exact. "HBM memory" will also capture "HBM memory chips", "HBM memory bandwidth" etc. Not case sensitive. It won't go fully semantic — it won't connect "HBM memory" to "DRAM" unless you add both. So use 2–3 word compound terms for signal quality: "AI" is too broad, "AI inference chips" is specific enough to mean something. Max 5 total slots: [ticker, theme_kw, custom_1, custom_2, custom_3].
