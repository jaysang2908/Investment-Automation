How to read this: Prime = Exit-Multiple headline (the site-wide method applied to every name). Perp = Gordon perpetuity cross-check — the sober number.
  • Both positive → FCF-backed. Cheap on cash flow, not just a terminal-multiple bet.
  • Prime positive, Perp negative → the upside is mechanical: a premium exit multiple applied to a hugely-compounded future EBITDA, not a cash-flow-cheap business today.
SBC-basis caveat: exit multiples are applied to SBC-adjusted EBITDA while peer multiples were quoted on standard EBITDA — this mechanically inflates the Prime headline for high-SBC software names. The perpetuity cross-check is unaffected and is the honest discipline.

Methodology notes
  • Horizon: 7-year explicit projection.
  • Scenarios: Bear / Base / Bull, constrained Bull ≥ Base ≥ Bear.
  • Terminal value: dual method — Perpetuity Growth + Exit Multiple (on SBC-adjusted EBITDA) — plus a Blended figure. Prime (the headline on this page) is the Exit Multiple output for every name.
  • Accounting basis: GAAP and Non-GAAP both modelled; the headline figure is Non-GAAP.
  • WACC: CAPM cost of equity = 4.70% risk-free + beta × 5.5% equity risk premium. Bear = Base +0.5pt, Bull = Base −0.5pt.
  • Historicals: sourced from SEC EDGAR 10-K / 10-Q filings.
  • Verification: every input source-commented; every model verified to within $0.05 vs. a Python mirror, with 0 broken references and 0 formula errors.
